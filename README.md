# Fracciona

Juego visual para practicar numerador y denominador con círculos divididos en partes iguales.

## Jugar en local

Abrí `index.html` en un navegador. No requiere instalación ni servidor.

## Publicar en GitHub Pages

El flujo de GitHub Actions de `.github/workflows/pages.yml` publica el sitio cada vez que hay cambios en `main`. En el repositorio, seleccioná **Settings > Pages > Build and deployment > Source > GitHub Actions**. La URL del juego aparecerá en el resultado de la ejecución del flujo.

La configuración de la partida y el ranking se guardan localmente en el navegador.
